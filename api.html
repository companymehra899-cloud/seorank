Example request

curl -X GET "https://api.optirank.io/v1/rankings" \
  -H "Authorization: Bearer $OPTIRANK_API_KEY" \
  -G -d "keyword=ai seo software" \
     -d "location=United States"

Example response

{ "keyword": "ai seo software",
  "position": 2,
  "change": 3,
  "engine": "google" }
